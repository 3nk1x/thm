# TryHackMe Write-Ups

Personal study notes and room write-ups from TryHackMe, kept for revision and reference.

## About

This repository collects reproducible walkthroughs of rooms I have completed — the
vulnerability, the exploitation steps, and the lessons learned. Everything here is for
educational and defensive-security learning only.

## Structure

- `notes/` — room write-ups, one Markdown file per room.

## Conventions

- One Markdown file per room, lowercase-hyphenated filename.
- Each write-up records the room name, the attack chain, reproducible steps, and takeaways.
- Lab IP addresses and other ephemeral target details are redacted or omitted; the techniques are the point.

## Disclaimer

All techniques were practised inside TryHackMe's authorised lab environment. Nothing here is
intended for use against systems you do not own or do not have explicit permission to test.
